# DoseCerta

Site pessoal de apoio à prescrição: doses por peso, condutas com opção SUS × ideal e receita pronta.

- `index.html` — página inicial com os módulos
- `pediatria/` — módulo de Pediatria
- `assets/gate.js` — senha de entrada (barreira simples, não é segurança forte)

Ferramenta de apoio. Sem dados de paciente: tudo roda no navegador.
